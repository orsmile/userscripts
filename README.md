# userscripts

瀏覽器使用者腳本（Tampermonkey）。

| 腳本 | 用途 |
|---|---|
| [Meta 圖片載入觀測](#meta-圖片載入觀測fna-replay) | 量 FB、IG、Threads 的圖片和影片要等多久，看是不是只有晚上尖峰才卡 |

## 安裝 Tampermonkey

1. 在 Chrome 或 Edge 安裝 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打開擴充功能管理頁（`chrome://extensions` 或 `edge://extensions`），點
   Tampermonkey 的「詳細資料」，打開「允許使用者指令碼」。較舊的版本沒有這個選項，
   改成打開右上角的「開發人員模式」。
3. 點下面各腳本的安裝連結，Tampermonkey 會跳出安裝畫面，按「安裝」。

裝好以後，腳本有新版時 Tampermonkey 會自動更新。

也可以用 [Violentmonkey](https://violentmonkey.github.io/)（Chrome、Edge、Firefox
都有），安裝方式一樣，點安裝連結就好。

## Meta 圖片載入觀測（fna-replay）

**安裝：** [fna-replay.user.js](https://github.com/orsmile/userscripts/raw/main/fna-replay.user.js)

Meta 會把熱門的圖片和影片放在各家網路業者機房裡的快取主機（FNA 節點）。
圖片不在快取裡時，主機要先去 Meta 那邊補，補得慢就會看到圖片一直出不來。
這個腳本在你瀏覽時，每幾秒抽一張你剛看到的圖或影片，記錄：

- **你實際等待的時間**：瀏覽器載入它花了多久。
- **HiNet 節點補檔**：把同一張圖改向中華電信 HiNet 的快取主機抓一次，再重抓一次。
  第一次慢、重抓快，就是補檔慢。

### 使用方式

1. 照常用 FB、IG 或 Threads，左下角會出現「Meta 觀測」按鈕，點開就是面板。
2. 白天和晚上 8 點以後都各滑一陣子。面板上有虛線底線的名詞，滑上去會有說明。
3. 結論出來以後，按「**下載 JSON**」存成檔案，交給要分析的人（或 AI agent）。
   「下載 CSV」可以用試算表打開。資料少的時候也可以按「複製 JSON」直接貼。

### 面板怎麼看

- **目前網路**：自動偵測你連線所屬的網路業者（ASN），每 10 分鐘更新一次。
  可以分出中華電信 HiNet 和 emome、遠傳和 Seednet、台灣大哥大、台灣固網、亞太、
  台灣之星，以及凱擘、中嘉、台灣寬頻、大大寬頻、大台北寬頻、台基科等系統台。
  換網路（例如改用手機熱點）也會跟著變，不同網路的資料可以在「顯示資料」分開看。
  有開 VPN 或分流時，Meta 看到的可能是另一個網路，請對照「Meta 分給你的主機」。
- **結論**：比較尖峰（晚上 20:00–24:00）和離峰時段，載入超過 1 秒的比例。
  尖峰和離峰各要 20 筆以上才會下結論。
- **每小時慢的比例**：每格是一小時，顏色越深代表慢的比例越高，虛線格是資料還不夠。
  這裡是所有日子合在一起算的。
- **每天的狀況**：每一列是一天，可以看出是哪一天、哪個小時在卡。下面的表格列出每天
  尖峰和離峰超過 1 秒的比例和筆數。某天尖峰沒什麼資料時，那天就還看不出來。
- **Meta 分給你的主機**：用中華電信的人通常是 `ftpe7`、`ftpe8` 或 `fkhh1`，
  其他業者會拿到不同的名稱。

### 隱私

- 只記錄時間、大小、HTTP 狀態碼、主機名稱和網路業者（ASN），**不記錄網址、IP 或你看的內容**。
- 偵測網路業者時會連到 RIPE（歐洲網路位址登記機構）的公開查詢 `stat.ripe.net`，
  它會看到你的 IP，但腳本只保存查到的業者編號和名稱。第一次執行時 Tampermonkey
  可能會詢問是否允許連到這個網域，請按允許。
- 資料只存在你自己電腦的 Tampermonkey 裡，不會自動上傳到任何地方，
  只有你按「下載」或「複製」並自己傳出去時才會給別人。
- 最多保留 1500 筆，滿了會刪掉最舊的。面板上的「清除資料」可以全部刪掉。
- 為了量補檔速度，它會多抓幾次同一張圖（每 6 秒最多一張，每張最多 4 MB）。
